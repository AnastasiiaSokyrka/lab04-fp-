# Лабораторна робота №4. Рекурсія та мемоізація в Python

Варіант 13

## Мета роботи

Реалізувати рекурсивну перевірку паліндрома і пошук найдовшого
неперервного паліндромного фрагмента рядка.

## Опис програми

- `core.py` містить рекурсивну й ітеративну перевірки, а також пошук з кешем і без.
- `algorithms.py` містить базові вправи з методички: тришляховий quicksort,
  рекурсивні обходи бінарного дерева, ітеративні DFS/BFS і дві версії Фібоначчі.
- `main.py` показує приклади, стан кешу, результат очищення та вимірювання `timeit`.

Перевірка порівнює крайні символи і зсуває обидві межі всередину.
База рекурсії — порожній або односимвольний проміжок.
Пошук приймає весь проміжок, якщо він паліндромний. Інакше порівнює
результати для проміжків без першого та без останнього символів.
За однакової довжини повертається найлівіший фрагмент.
Порівняння чутливе до регістру й пробілів та відбувається за кодовими
точками Unicode. Наприклад, для `babad` результатом є `bab`.

Кеші за межами `(left, right)` належать одному вхідному рядку. Із
мемоізацією обчислюється не більше O(n²) станів, а глибина рекурсії
лишається O(n). Порівняння часу використовує нові кеші на кожному виклику.
CPython не виконує оптимізацію хвостових викликів (TCO). Поточний
ліміт показує `sys.getrecursionlimit()`. Для довгих рядків
`is_palindrome_iter` працює без рекурсивного стеку.

## Встановлення

Потрібен Python 3.10 або новіший. Відкрийте термінал у каталозі цієї лабораторної та виконайте:

```text
python -m venv .venv
```

Активуйте середовище командою `.venv\Scripts\activate` у Windows CMD,
`.\.venv\Scripts\Activate.ps1` у PowerShell або `source .venv/bin/activate`
у Linux/macOS, далі встановіть залежності:

```text
python -m pip install -r requirements.txt
```
